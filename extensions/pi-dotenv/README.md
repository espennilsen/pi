# @e9n/pi-dotenv

> **⚠️ Deprecated** — this extension is a no-op. It is kept only for backwards compatibility and is safe to remove.

All extensions now read configuration directly from `settings.json`. The `"env:VAR_NAME"` syntax (for referencing environment variables) is handled natively by extensions like [pi-channels](https://www.npmjs.com/package/@e9n/pi-channels) and [pi-webserver](https://www.npmjs.com/package/@e9n/pi-webserver) — no loader extension is required.

## Install

```bash
pi install npm:@e9n/pi-dotenv
```
