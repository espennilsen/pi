# pi-myfinance

Personal finance tracking extension for [pi](https://github.com/mariozechner/pi-coding-agent).

Track accounts, transactions, budgets, goals, and recurring expenses — all from your terminal or Telegram. AI-powered insights help you understand your spending patterns.

## Install

Add to your pi workspace's `.pi/extensions/`:

```bash
ln -s ~/Dev/pi-myfinance ~/.pi/agent/extensions/pi-myfinance
```

## Features

- **Accounts** — checking, savings, credit, cash, investment
- **Transactions** — income/expense tracking with categories and tags
- **Budgets** — envelope-style monthly/annual budgets per category
- **Goals** — savings targets, debt paydown, purchase goals
- **Recurring** — subscriptions, salary, rent with auto-processing
- **Reports** — spending summaries, trends, category breakdowns
- **CSV import/export** — bring your bank data in
